## 验证详情

通过启动本地静态 Web 服务，我们在内置浏览器环境（排除了先前无效的 Chrome 路径干扰）中进行了完整的交互流验证：

1. **粒子背景与自适应测试**：
   - Canvas 粒子流以平滑视差随鼠标滑动变化。
   - 页面成功在移动端宽度下收缩适配，无水平溢出。
2. **3D 平滑翻转**：
   - 移入卡片区域时，卡片顺利绕 Y 轴进行 180 度翻转；移出时自动翻回。
   - 点击卡片时，会在卡片容器上切换 `is-flipped` 状态类，保证移动端触屏同样可翻转。
3. **按钮属性检测**：
   - **“捕获星空”按钮**：`href="1000104636.jpg" download="1000104636.jpg"`。下载属性正确配置，且绑定了事件冒泡拦截，点击下载时卡片不会发生错误翻转。
   - **“返回地球”按钮**：`href="/"`。链接路径配置无误。
