# 404 错误页面重构计划

本计划旨在为个人网站 `artnh.cn` 重新设计并实现一个极具科技感与浪漫色彩的 404 错误页面。页面将在正中央展示一个 3D 翻转的交互卡片，并融合深色调、流光粒子与精美微交互。

## 用户评审要点
1. **移动端交互优化**：为照顾没有鼠标悬停（Hover）的移动端设备，我们除了保留 `hover` 翻转外，还将添加 JavaScript 支持：点击卡片同样可以进行翻转。
2. **动态背景**：为提升“科技感”和“浪漫色彩”，计划在页面背景中使用 Canvas 绘制极其轻量且流畅的动态粒子星空（带微弱闪烁与流星效果）。

## 开放性问题
- 目前无，本方案已覆盖所有提出的具体要求。如有额外设计偏好（例如特定配色微调），请在审批时告知。

## 拟进行的修改

### 404 错误页面

#### [NEW] [404.html](../404.html)
- **结构设计**：
  - 容器居中布局。
  - `card-container` 具备 `perspective` 视距属性。
  - `card` 实现 `transform-style: preserve-3d` 3D 空间，Hover 时绕 Y 轴旋转 180 度。
  - `card-front`（正面：第一幕 · 迷航）：展示 404 状态与迷航文案，采用半透明玻璃质感。
  - `card-back`（背面：第二幕 · 邂逅）：展示邂逅文案，背景设置为自适应的 `1000104636.jpg`，并提供“捕获星空”与“返回地球”按钮。
- **背景设计**：
  - 渐变暗色调（从 `#050508` 暗夜蓝到 `#000000` 纯黑）。
  - 使用 Canvas 渲染动态星空粒子，丰富画面视觉层次，使其灵动而不单调。
- **交互与动画**：
  - 翻转平滑过渡（`cubic-bezier(0.4, 0, 0.2, 1)`，0.8秒）。
  - 按钮悬停发光与流光动效。
  - “捕获星空”通过带有 `download` 属性的链接实现高清原图下载。
  - “返回地球”跳转回 `/`。

## 验证计划

### 自动验证
- 无特定自动化测试，我们将采用浏览器测试。

### 手动验证
1. **本地预览**：在浏览器中打开生成的 `404.html` 页面。
2. **交互测试**：
   - 验证鼠标悬停在卡片上时，卡片是否平滑 3D 翻转 180 度。
   - 验证移动端（或点击时）翻转是否工作正常。
   - 验证“捕获星空”按钮点击后是否能够触发 `1000104636.jpg` 图片的下载。
   - 验证“返回地球”按钮点击后是否能正确指向主页（`/`）。
3. **视觉走查**：
   - 验证卡片背面图片 `1000104636.jpg` 是否完美居中并且覆盖（`background-size: cover`）。
   - 检查背景 Canvas 粒子星空是否流畅，是否有性能卡顿。
   - 确认整体配色与主站风格相得益彰，且充满科幻和浪漫气质。
